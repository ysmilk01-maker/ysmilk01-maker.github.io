# 첫 화면 3D 개편 — 2026-09-13

## 변경

- `일상에, 작은 재미를.`을 큰 두 줄 제목으로 배치하고 순서대로 등장시켰다.
- 검정 바탕 오른쪽에 파랑·보라 3D 매듭, 작은 구체와 궤도를 배치했다.
- WebGL 메시가 천천히 회전하며 마우스 위치에 반응한다. 외부 엔진이나 새 라이브러리를 추가하지 않았다.

- 일시정지 버튼, 동작 줄이기, 화면 밖·숨긴 탭에서 렌더 중단, WebGL 실패 시 기존 이미지 대체를 넣었다.
- 앱·개발 소식 안내, 공식 플랫폼 링크와 개인정보 본문은 유지했다. 상세 HTML의 변경은 공통 파일의 캐시 해시뿐이다.

## 유지보수와 배포

- 수정 위치: `index.html`의 `.hero--kinetic`, `style.css`의 첫 화면 3D 구간, `site.js`의 WebGL IIFE.
- 상세 스타일 빌드 표식 위에 새 CSS를 두어 상세 재생성 시 보존한다.
- 앱·개인정보 페이지의 CSS·JS 해시는 `python tools/cache_bust.py`로 갱신한다.
- `git pull --rebase` 후 캐시 검사를 다시 통과한 커밋을 푸시한다.
- 해당 소스로 `python build-plugin.py --bump --src <저장소>`를 실행해 워드프레스 플러그인을 교체하고 WP Super Cache를 비운다.
- 배포 완료 여부·버전·커밋·공개 URL 검증 결과는 `codex-inbox`의 별도 작업결과에 기록한다.

## 모바일 첫 화면 높이 보정 — 2026-09-13 추가

- 사용자 휴대전화 캡처에서 3D 아래가 브라우저 바 뒤로 잘리는 문제를 수정했다.
- 모바일 제목을 기존 최소 48px에서 36~44px로 줄였다. 390px 폭에서는 약 38px다.
- 위 여백 45→18px, 제목 아래 설명 간격 23→12px, 버튼 위 간격 24→16px로 조정했다. 버튼 누름 영역은 최소 44px를 유지한다.
- 작은 뷰포트 높이(svh)에서 내비게이션·하단 조작부 공간을 빼고 남은 공간을 3D에 배정한다. 3D 투영 크기를 캔버스의 짧은 변에 맞춰 세로로 긴 화면에서도 회전할 때 옆이 잘리지 않게 한다.
- 모바일 배경광을 자체 영역 안에 가둬 키보드 포커스로 첫 화면 내부만 스크롤되는 현상을 막았다. 히어로에는 기존 overflow: hidden을 유지해 회전 중 텍스트 합성이 깨지지 않도록 했다.
- iOS에서 상단 기호가 초록 이모지로 표시되지 않도록 텍스트 표현 선택자를 붙였다.
- 브라우저 320×568, 390×664, 약 393×724, 390×844에서 캔버스 전체가 첫 뷰포트에 들어오고 가로 넘침이 없음을 확인했다. 1280px 데스크톱 레이아웃도 확인했다.
- 390×724 정지 상태에서 캔버스 하단 약 663px. 움직임 멈춤·재생, Tab 앱 카드 포커스 확인.
- 데스크톱 제목·3D 구도와 새 글자색 변경 없음. JavaScript는 캔버스 비율에 맞춘 투영 크기만 보정했다. 실제 Safari 기기의 재확인은 별도다.
- 모바일 문구는 즉시 표시한다. 화면 크기 전환 뒤에도 제목이 가려지지 않게 모바일의 텍스트 등장 변형만 제거하고 3D 회전은 유지했다.
