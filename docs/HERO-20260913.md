# 첫 화면 3D 개편 — 2026-09-13

## 변경

- `일상에, 작은 재미를.`을 큰 두 줄 제목으로 배치하고 순서대로 등장시켰다.
- 검정 바탕 오른쪽에 파랑·보라 3D 매듭, 작은 구체와 궤도를 배치했다.
- WebGL 메시가 천천히 회전하며 마우스 위치에 반응한다. 외부 엔진이나 새 라이브러리를 추가하지 않았다.
- 로고가 본문을 덮던 도입 화면을 제거했다. 제목은 CSS, 3D는 전용 렌더러가 맡는다.
- 좁은 화면은 제목과 조형물을 위아래로 배치하고 렌더 해상도를 제한한다.
- 일시정지 버튼, 동작 줄이기, 화면 밖·숨긴 탭에서 렌더 중단, WebGL 실패 시 기존 이미지 대체를 넣었다.
- 앱·개발 소식 안내, 공식 플랫폼 링크와 개인정보 본문은 유지했다. 상세 HTML의 변경은 공통 파일의 캐시 해시뿐이다.

## 유지보수와 배포

- 수정 위치: `index.html`의 `.hero--kinetic`, `style.css`의 첫 화면 3D 구간, `site.js`의 WebGL IIFE.
- 상세 스타일 빌드 표식 위에 새 CSS를 두어 상세 재생성 시 보존한다.
- 앱·개인정보 페이지의 CSS·JS 해시는 `python tools/cache_bust.py`로 갱신한다.
- `git pull --rebase` 후 캐시 검사를 다시 통과한 커밋을 푸시한다.
- 해당 소스로 `python build-plugin.py --bump --src <저장소>`를 실행해 워드프레스 플러그인을 교체하고 WP Super Cache를 비운다.
- 배포 완료 여부·버전·커밋·공개 URL 검증 결과는 `codex-inbox`의 별도 작업결과에 기록한다.
