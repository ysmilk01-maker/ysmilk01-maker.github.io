## 남은 일 — 급한 순서

1. **[완료] 캐시 버스팅.** `tools/cache_bust.py`가 공통 CSS·JS의 내용 해시를
   `?v=`에 붙인다. 상세 빌드 마지막에 자동 실행하며 메인·개인정보 페이지도 함께
   갱신한다. 공통 파일만 바꿨다면 `python tools/cache_bust.py`, 푸시 직전에는
   `python tools/cache_bust.py --check`로 확인한다. 인앱 브라우저 실기기 확인은 별도다
2. **[완료] 앱별 개인정보 안내.** AI 진단을 추가하고 기기 저장과 서버 저장,
   날씨·광고 요청을 구분했다. 스도쿠는 웹 공개·스토어 준비 중 상태를 명시한다. 비트웨이브·오늘도 출격의 웹 기록 저장과 외부 파일 요청도 안내한다
3. **코인 랭킹 5위에 「연결테스트」 행.** 서버(Supabase)에 남은 테스트 데이터라
   사이트에서 고칠 게 아니다. 대표가 SQL 을 실행하면 사라진다. 그때까지 페이지에
   그대로 보인다 — 클라이언트에서 숨기는 꼼수는 넣지 않는다
4. **첫 화면 조형물 조정 여지.** `index.html` 의 `--x/--y/--w` 와 `data-depth`,
   `site.js` 의 떠다니기 폭(`9 + 7 * d`)·시차 폭(`16 * d`, `12 * d`). 실기기에서
   보고 정한다. 아직 실기기 확인 전
5. **AI 앱 OG 이미지.** 모든 상세 페이지가 `img/og.png` 하나를 쓴다. 앱별 OG 를 만들면
   쓰레드·카카오톡 미리보기가 앱마다 달라진다. 1200×630, 검정 바탕, 앱 색 하나
6. **`lab/` 의 파일 크기.** 5.6MB. 이 사이트의 것이 아니라 손대지 않지만, 저장소가
   무거워지면 별도 저장소로 빼는 논의를 할 것

## 하지 않기로 한 것

  (개인사업자는 코스콤 계약 불가). 페이지는 「전일 종가」라고 정직하게 쓴다
- Liquid Glass 류 라이브러리 — html2canvas 기반이라 웹뷰에서 무겁다. 유리 효과는
  `backdrop-filter` 로 충분
- 앱 화면을 AI 로 그리는 것 — 진짜 스크린샷이 있다. 첫 화면 조형물만 AI 그림이다
- 프레임워크·빌드 도구 도입
