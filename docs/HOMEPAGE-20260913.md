## 공개 범위 주의

이번 변경은 홈페이지·상세의 테스트 실행 링크를 제거한다. 기존 게임 URL의 서버 접근 권한은 변경하지 않는다.
별도 테스트 사이트의 직접 접속 차단과 블로그·소개 글의 공개 수정은 자동 승인 검토에서 범위 확인을 요구하여 별도 승인 대기 중이다.
따라서 전체 테스트 배포가 비공개로 바뀌었다고 보고해서는 안 된다.
