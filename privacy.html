비트웨이브는 원스토어 출시일부터 보상형 광고를 제공합니다. 광고 노출·완료 여부와 보상 처리 상태를 확인해 연주권 등의 보상을 지급하며, 광고 사업자는 광고 제공과 중복 노출 방지를 위해 광고 식별자와 기기·네트워크 정보를 처리할 수 있습니다. 현재 웹 플레이테스트에는 적용되지 않으며, 출시 패키지에서 확정되는 광고 사업자와 세부 처리 항목은 실제 운영 전에 이 방침에 반영합니다.

맞춤 광고를 원하지 않으시면 안드로이드 설정 → 개인정보 보호 → 광고에서 광고 ID를 삭제하거나 다시 설정하실 수 있습니다. 광고 자체는 계속 표시되지만 관심사 기반 맞춤은 중단됩니다.

7. 외부 서비스와 처리업체

이용자 정보를 판매하지 않습니다. 서비스 운영과 홈페이지 방문 분석에 필요한 범위에서 아래 외부 서비스 또는 처리업체를 사용합니다.

  • Supabase — 코인 앱과 국내주식 앱의 랭킹·게시판 데이터 저장. 비트웨이브 Android 계정 버전의 사용자 인증과 계정 프로필·설정, 연주권, 우편, 플레이·점수·별점, 이용 권한 데이터 저장
  • Google 로그인 — 비트웨이브 Android 계정 버전의 로그인과 계정 인증. Google 계정 식별자, 이메일 주소와 기본 프로필 정보가 인증 과정에서 처리될 수 있으며 Google 비밀번호는 비트웨이브에 전달되지 않습니다.
  • 비트웨이브 웹 랭킹 서버 — 웹 플레이테스트의 익명 식별자, 자동 생성 표시 이름, 플레이 조건·점수와 랭킹 저장
  • 공공데이터포털(금융위원회) — 국내주식 앱의 주식 시세 조회. 시세를 받아오기만 하고 이용자 정보는 보내지 않습니다.
  • 기상청 — 사주 앱에서 사용자가 선택한 지역의 날씨 조회
  • 토스(비바리퍼블리카) — 토스 미니앱의 실행 환경과 인앱광고 제공
  • Google(AdMob) — AdMob이 적용된 원스토어·구글플레이 안드로이드 앱의 광고 제공. 비트웨이브의 출시 광고 사업자는 출시 패키지 확정 후 이 방침에 반영합니다.
  • Google(Analytics) — 홈페이지 방문 경로와 이용 현황 분석. 처리 정보와 수집 중단 안내는 위 홈페이지 방문 분석 항목을 참고해 주세요.
  • Google(AdSense) — 홈페이지에 광고를 적용하는 경우 광고 제공, 빈도 제한, 부정 이용 방지와 성과 측정. 처리 정보와 지역별 동의 안내는 위 홈페이지 광고와 쿠키 항목을 참고해 주세요.
